# 汗牛充栋桌面阅读

Electron（MIT）客户端复用 NAS 上现有 Vue 阅读器、登录和阅读进度；不内嵌后端，不下载完整书库。仅新增 Electron 开发依赖，远程页面关闭 Node 集成、开启上下文隔离和沙箱，IPC 限定主窗口与当前书库来源。不允许跨来源跳转、弹出窗口、下载或网页权限请求。

## 开发与打包

先部署包含本次前端、后端改动的书库，再在 `desktop` 目录运行：

```sh
npm ci
npm start
npm test
npm run package
```

应用版本唯一读取 `../frontend/package.json`，桌面 package.json 不单独维护版本。打包脚本复用 Electron 官方发行文件，无其他打包依赖；输出到 `desktop/dist/aibook-版本-平台-架构`。同版本同平台重复打包会拒绝覆盖，应先自行移走旧产物。

Windows 11 在 Windows 构建并运行目录中的「汗牛充栋.exe」，必须保留整个目录。macOS 在 Mac 构建，可将「汗牛充栋.app」放入应用程序目录；分别使用 Apple Silicon 或 Intel Node 环境构建对应架构。不提供跨平台构建或签名绕过。macOS 发布前应使用自己的 Apple Developer 身份完成签名和公证；当前输出是未签名开发包，修改官方 bundle 后原签名不可用。Windows 发布版同样需要另行签名。Electron 更新由维护者升级锁定版本并重新打包，不自动执行远程更新代码。

## 使用

首次填写 HTTP/HTTPS 根地址（不支持子路径部署），在 App 内重新登录。服务地址在本机保存；每个服务来源使用独立 Electron 会话，不共享不同书库登录。局域网可使用 HTTP，跨公网应配置 HTTPS。书库地址更换后从托盘菜单或窗口设置重新连接。

选书进入正式阅读后，右下角「隐身阅读」进入透明阅读，退出后恢复原主题。窗口设置包含背景、文字及整体不透明度、置顶、两档尺寸和鼠标穿透。拖动右下角点阵手柄移动窗口。整体与文字不透明度最低 15%，背景可设 0%。工具条在隐身状态变淡，鼠标移入或键盘焦点进入后恢复。

- `Ctrl/⌘ + Shift + H`：隐藏／恢复窗口。
- `Ctrl/⌘ + Shift + R`：恢复到普通阅读并退出鼠标穿透。
- 托盘／菜单栏：恢复窗口、更换书库、退出。快捷键注册失败会提示，恢复快捷键不可用时禁止穿透。
- 关闭窗口留在托盘，使用「退出应用」结束进程。

透明度、置顶按账户保存到 NAS；阅读进度沿用现有阅读器。隐藏、穿透、隐身启用状态不跨会话保存。窗口位置和大小暂不持久化。背景透明支持现有 TXT/HTML 阅读表面；PDF 固定页面、EPUB 内嵌文档仍可能保留自己的不透明背景，不承诺透明。离开正式阅读自动退出隐身。屏幕共享和录屏仍可能显示窗口，不提供防录屏功能。使用旧版服务端或前端时请先升级，旧版前端不显示桌面控制条，可用托盘切换服务。

## 验证边界

策略测试验证地址约束、会话隔离及窗口 IPC 数值校验。安装 Playwright 后可运行 `node test/smoke.cjs`（或通过 DESKTOP_PLAYWRIGHT_PATH 指定现有安装），验证真实 Electron 启动、连接、沙箱、透明度、置顶、穿透开关、隐藏及恢复。七种阅读皮肤另有前端 `test:desktop-reader` 浏览器回归。

已在当前 Windows 环境生成未签名 x64 便携包并完成原生冒烟测试；未验证真实 NAS、人工视觉合成、快捷键冲突、多屏缩放或 macOS 实机，不能把自动化测试视为双平台验收。离线缓存和原生安装向导不属于本版。
