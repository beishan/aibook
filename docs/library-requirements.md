# 个人主题图书馆需求文档

- 文档版本：1.0
- 编写日期：2026-10-29
- 关联需求：REQ-20261029-004
- 状态：需求细化已完成，功能尚未开发；本文件作为后续实现与验收基线。
- 确认依据：个人使用；多个独立图书馆；各馆拥有首页、书架、书单、收藏；可配置样式、布局与首页；从现有书库添加书籍。跨馆进度共享及下文具体交互为本次细化方案。

## 1. 目标与范围

在现有总书库之上增加个人主题阅读空间。用户可以建立文学馆、历史馆、技术馆等多个图书馆，以不同内容组织和视觉风格开展阅读。

总书库负责书籍入库、文件、版本、元数据及回收站；图书馆负责选书、组织、展示与阅读入口。添加书籍只建立关联，不复制文件、不移动原书，不自动加入原有个人书架。

### 1.1 首期范围

- Web 桌面与移动端适配，提供独立的图书馆列表页与馆内页面。
- 创建、编辑、排序、删除多个图书馆，不设产品层面的固定馆数量上限，列表分页加载。
- 每馆独立的首页、书架、书单、收藏，以及样式和布局配置。
- 从总书库、书籍详情或馆内选书器添加现有书籍，支持批量与多馆选择。
- 跨馆复用现有阅读器、进度、书签、笔记及版本机制。
- 配置绑定当前账户并在服务端保存，跨浏览器、设备、会话恢复。

### 1.2 首期不包含

- 公开发布、访客访问、馆内成员、分享链接及协作权限。
- 独立上传、爬取、元数据编辑器或文件管理系统。
- 按馆隔离进度、自动重读轮次、跨格式强制位置换算。
- 任意拖拽页面编辑器、自定义脚本、HTML、CSS、远程背景地址或插件市场。
- Android/iOS 原生馆管理、OPDS 等协议中的馆映射；原有客户端继续使用既有书籍和进度能力。
- 纯有声作品与专属收听首页模块；含电子版的作品可入馆，详情中已有的有声版本入口继续使用现有规则。

## 2. 核心数据与归属规则

| 对象 | 归属与规则 |
|---|---|
| 文件、版本、书名、作者、封面、分类、标签 | 沿用总书库，同一本书各馆同步展示，不生成馆内副本 |
| 图书馆 | 归当前账户所有；其他账户不可读取或修改；管理身份不自动形成共享入口 |
| 馆藏关系 | 图书馆 + 书籍唯一；同一本书允许加入多个馆 |
| 阅读进度 | 沿用账户 + 书籍汇总进度与账户 + 文件版本进度；不得增加图书馆维度 |
| 书签、笔记、阅读时长、已读状态 | 沿用现有作用域及统计规则，跨馆共用，不重复计时 |
| 馆内书架分组、次序 | 每馆独立，不同步到原有个人书架或其他馆 |
| 馆内书单 | 每馆独立，成员必须属于本馆 |
| 馆内收藏 | 当前账户 + 图书馆 + 书籍；与原有收藏互不修改 |
| 首页、主题、展示偏好 | 按当前账户及图书馆保存到服务端 |

书籍身份以现有书籍 ID 为准，不按书名或文件名去重。两本同名但不同 ID 的书仍视为不同书籍；版本切换沿用现有版本定位规则，不能因为跨馆共享就将不同版本强制对齐。

原有总书架、分组、书单和收藏保持原样，首期不自动迁移、不聚合馆内数据。馆内操作必须使用明确的“本馆收藏”“移出本馆”等文案；进入现有书籍详情后，原有全局操作仍按原范围执行，不静默改成馆内操作。

## 3. 页面与导航

建议新增 `/libraries` 列表入口；现有 `/books` 总书库与 `/shelf` 个人书架继续保留。馆内建议路由如下，实际命名由实施阶段与现有路由规范对齐：

| 页面 | 建议路径 | 主要内容 |
|---|---|---|
| 图书馆列表 | `/libraries` | 馆卡片、搜索、创建、排序、管理 |
| 馆首页 | `/libraries/:libraryId` | 馆头与首页展示模块 |
| 馆书架 | `/libraries/:libraryId/shelf` | 本馆全部书籍、分组、筛选和排序 |
| 馆书单 | `/libraries/:libraryId/booklists` | 本馆书单列表 |
| 馆书单详情 | `/libraries/:libraryId/booklists/:listId` | 书单成员与次序管理 |
| 馆收藏 | `/libraries/:libraryId/favorites` | 本馆已收藏书籍 |
| 馆设置 | `/libraries/:libraryId/settings` | 基本资料、外观、首页配置、删除 |

馆内固定显示馆名、返回图书馆列表、切换图书馆、添加书籍和设置入口。首页、书架、书单、收藏采用带平滑移动指示器的滑块分段控件；支持键盘切换、可见焦点、移动端横向滚动和减少动态效果偏好。

书籍卡片先进入现有详情，再选择版本阅读。详情、阅读器应保留可信的来源馆上下文；返回时恢复来源页面、搜索和页码。上下文失效则回到图书馆列表；不得接受任意外部返回地址。

## 4. 图书馆管理

### 4.1 列表与创建

- 馆卡片显示封面、名称、简介、有效馆藏数；点击进入该馆首页。
- 支持按馆名搜索，默认按手工次序排序，可切换最近创建；手工次序持久化。
- 列表每页默认 24 项，可选 12、24、48、96 项，按账户保存。
- 创建时名称必填，去除首尾空白后为 1–50 个字符；同一账户内名称不得重复。简介可选，最多 500 个字符。
- 创建时选择预设封面和首页模板，默认使用“简洁”模板；不要求先选书。
- 空馆首页展示“从书库添加书籍”的引导，创建成功进入馆首页。
- 首期使用随应用提供的封面与背景，选项在正式开发时提供预览，不依赖外部图片服务。

### 4.2 编辑与删除

名称、简介、封面与外观可修改；设置显式保存，成功后才提示生效。离开未保存的设置时提示保存或放弃；保存失败保留草稿供重试。

删除馆时显示馆名、馆藏数、书单数及影响说明，二次确认。确认后删除该馆、馆藏关联、分组、书单、馆内收藏与馆配置；不删除总书库书籍、文件、原有个人组织数据及阅读记录。首期无图书馆回收站，删除提示须明确馆内组织数据无法恢复。

## 5. 添加书籍与馆书架

### 5.1 添加流程

1. 总书库或详情提供“添加到图书馆”；馆内提供“从书库添加”。
2. 总书库支持当前选择的多本书；目标馆可多选，可在弹窗内创建图书馆并继续添加。
3. 馆内选书器只展示当前账户可访问、未回收且含可用电子版的书籍，支持书名、作者检索与分页。已在馆中的书标为“已添加”，不能重复选择。
4. 提交前显示书籍数量与目标馆；已有关系视为成功跳过，重复点击或重试不得生成重复记录。
5. 批量结果区分新增、已存在、无权限/已失效、失败；部分失败显示原因并允许只重试失败项，不用一个成功提示掩盖失败。
6. 新加入的书进入本馆“未分组”，按加入时间降序显示；不会自动收藏或加入书单。

批量操作默认仅处理明确勾选的书籍；跨页全选须有独立数量提示，首期不提供隐含的全库添加。接口应限制单次请求规模并在超限时说明，不能要求一次加载全库。

### 5.2 书架组织

- “全部”和“未分组”为系统视图；可新建、改名、排序和删除自定义分组。
- 每本书在同一馆最多属于一个自定义分组；不同馆的分组互不影响。
- 分组名去除首尾空白后 1–50 字符，同馆内唯一，不得与系统视图重名。
- 删除分组将成员放回未分组，不移出本馆；书单可跨分组收录。
- 搜索本馆书名、作者；支持分类、标签及未读/在读/已读筛选，状态沿用真实阅读记录。
- 支持按加入时间、书名、作者、最近阅读排序；自定义分组支持手工书籍排序。筛选或搜索期间禁用手工排序并提示原因。
- 每页默认 24 项，可选 12、24、48、96 项；当前馆的书架、收藏及书单详情共用每页数量偏好，页码各自独立。查询变化回第一页，删除后回到有效页码。
- 单本及批量操作提供移动分组、加入本馆书单、设置/取消本馆收藏、移出本馆。全局文件和元数据维护引导进入总书库。

### 5.3 移出本馆

移出前确认并说明：该书将同时从本馆书架、书单、收藏和手动精选中移除，原书与阅读记录保留。关系清理在同一事务内完成。再次入馆视为新加入，不自动恢复旧分组、收藏或书单关系。

## 6. 馆内书单与收藏

### 6.1 书单

- 支持创建、编辑、删除及排序；书单包括名称、简介和手工次序。
- 名称去除首尾空白后 1–50 字符，同馆内唯一；简介最多 500 字符。
- 一本书可进入本馆多个书单，同一书单内不能重复；书单内容可手工排序。
- 从书单选书时默认只选本馆馆藏；欲从总书库添加时，明确提示“同时加入本馆及本书单”，两项关联原子完成。
- 从书单移除书籍只删书单关系，不移出本馆或取消收藏；删除书单亦不删除成员书籍。
- 原有书单不自动导入或与馆内书单联动。首期不提供整单复制，用户可批量选书添加。

### 6.2 收藏

本馆书架卡片提供本馆收藏开关，收藏页仅显示当前馆收藏。取消收藏不移出馆；在 A 馆收藏不改变 B 馆或原有收藏。收藏页支持书名/作者搜索及收藏时间、书名、最近阅读排序，默认按收藏时间降序。

## 7. 首页与外观配置

### 7.1 模板和布局

首期提供“简洁”“书架”“专题”三种预设模板。模板只设置页面样式、卡片形式与模块默认顺序，不更改馆藏、书单或阅读数据。切换模板前可预览；覆盖现有布局配置需明确确认。

- 主题色：预设色板；背景：纯色或内置纹理；需确保文字对比度和深浅色可读性。
- 书架展示：封面网格或列表；封面尺寸：小、中、大；响应式计算列数，窄屏不照搬桌面列数。
- 首页馆头：显示馆名，可选择显示简介、封面和有效馆藏数。
- 馆外观只作用于馆内页面，不覆盖系统整体主题或阅读器设置。
- 配置可预览、保存和恢复默认；恢复默认需确认，保留全部馆藏和组织数据。

### 7.2 首页模块

每种模块首期最多一个，可启停与调整顺序；继续阅读、精选、最近加入最多展示 12 本，推荐书单最多 6 个。可选择 4/8/12 本或 2/4/6 个，默认分别为 8 本和 4 个书单。

| 模块 | 数据与交互 |
|---|---|
| 继续阅读 | 当前馆中有真实阅读记录且未读完的书，按最后阅读时间降序；复用汇总进度及对应版本；进入详情后继续阅读 |
| 精选书籍 | 手动从本馆选书并排序，不自动替换缺失项 |
| 推荐书单 | 手动选择本馆书单并排序，点击进入馆书单详情 |
| 最近加入 | 按有效馆藏的加入时间降序展示 |

默认顺序为继续阅读、精选书籍、推荐书单、最近加入。无数据模块在浏览态隐藏，设置态显示空状态与配置入口；全部为空时展示选书引导。关闭全部模块时保留馆头和进入书架按钮。

“查看全部”分别进入本馆书架的在读视图、本馆书单列表或按加入时间排序的本馆书架；手动精选最多 12 本，首期不增加单独的精选管理页面。

## 8. 阅读、统计与异常一致性

- 同一账户从 A 馆读到某位置，再从 B 馆或总书库打开同一版本，应恢复相同的服务端位置。版本进度与书籍汇总关系沿用当前服务，不以进度百分比最大值代替最近位置。
- 本需求不改变多设备进度冲突、离线同步或阅读会话去重规则；已有规则须回归验证。
- 首页继续阅读在重新进入或刷新时读取最新服务端数据，不能永久使用过期缓存。
- 不新增跨馆累加的全局时长统计；如显示本馆统计，按当前有效馆藏去重统计，是当前馆藏的阅读情况，不能解释为“在本馆发生的阅读活动”。
- 原书移入回收站：馆内不再展示、计数或参与首页；保留组织关联，恢复原书后恢复原关联及次序。
- 原书彻底删除：清除馆藏及相关组织关系，原有全局删除规则继续生效。
- 书籍合并：迁移到目标书籍并去重。同馆存在源和目标时保留目标分组与排序；只存在源时沿用源分组。收藏取并集，书单成员去重；手动精选优先保留已有目标位置，否则保留迁移位置。合并后馆藏时间取相关关系最早加入时间。
- 合并、回收或移出使书单/模块变空时使用空状态，不保留可点击的失效卡片。
- 请求其他账户的馆、馆内书单或书籍关联时，服务端校验所有权和归属；不能只靠前端隐藏入口。
- 馆被其他设备删除后显示不可用提示并回到列表。断网与保存失败给出可重试反馈，保存成功前不宣称配置已同步。
- 同一馆设置采用修订号检测并发修改，冲突时保留本地草稿并提示重新加载，避免静默覆盖。

## 9. 实现边界与数据设计建议

以下为实施建议，表名与接口不是本次已交付能力。

- 新增图书馆实体，保存所有者、名称、简介、预设封面、排序、展示配置、修订号及时间字段。
- 新增馆藏关联，保存图书馆、书籍、分组、次序、收藏状态与时间；数据库唯一约束覆盖图书馆和书籍。
- 新增馆分组与馆书单及其成员关系；所有查询限定当前用户和目标馆，成员添加验证馆藏归属。
- 馆内书单优先评估复用现有 `BookList` 服务能力；如增加可空馆作用域，旧查询必须显式限定全局作用域，避免馆内书单泄漏到原页面。不能未经影响评估直接复用原接口。
- 复用 `ReadingProgress` 与 `VersionReadingProgress`，不迁移既有进度、不建立馆内进度副本。
- 主题、模板与模块配置使用有结构和大小限制的服务端配置字段；本地存储只能作草稿/缓存，不作为已登录偏好的唯一来源。
- 服务端分页、批量写入、关联去重和必要的用户/图书馆/排序索引；馆列表及首页避免逐书额外查询。
- 新增关系的备份与恢复必须纳入现有备份体系；恢复后引用、排序与配置可用，旧备份缺少馆数据时视为空馆列表，不影响原书库。
- 首期不引入新的服务或依赖。本次仅编写需求，未进行开源候选的最新调研；进入功能开发前须按 AGENTS.md 调研匹配方案，评估许可证、活跃度、安全、资源及 NAS 集成成本。如需引入依赖、代码或服务，先说明范围、收益与风险并获得确认。

## 10. 验收标准

| 编号 | 场景 | 预期结果 |
|---|---|---|
| LIB-01 | 创建两个馆并刷新或换设备登录 | 两馆资料、顺序和独立首页可恢复；其他账户不可见 |
| LIB-02 | 同书批量加入两馆，重复提交 | 每馆仅一条关联，文件数量不变，结果区分新增和已存在 |
| LIB-03 | A 馆分组、收藏、建书单 | B 馆及原有个人书架、收藏、书单保持原状态 |
| LIB-04 | A 馆阅读后从 B 馆打开同书同版本 | 恢复相同位置，书签笔记可用，时长不因馆数量重复累计 |
| LIB-05 | 切换同书的不同版本或有声版本 | 沿用既有版本/收听定位规则，不强制对齐 |
| LIB-06 | 从总书库向馆内书单选书 | 明示双重加入，成功后同时存在馆藏和书单关系；失败不残留半完成关系 |
| LIB-07 | 移出本馆后再次加入 | 本馆旧组织关系清除，再加入进入未分组；原书和阅读记录保留 |
| LIB-08 | 删除书单、分组或图书馆 | 分别按既定范围清理，不误删总书库书籍与阅读记录 |
| LIB-09 | 调整模板、颜色、模块顺序并保存 | 当前馆生效、跨设备恢复，其他馆与阅读器设置保持原值 |
| LIB-10 | 回收、恢复、彻底删除及合并书籍 | 展示、计数、引用与去重符合第 8 节规则，无失效链接 |
| LIB-11 | 空馆、空书单、所有模块关闭、网络失败 | 引导和错误反馈可用，可进入书架或重试，无虚假成功提示 |
| LIB-12 | 窄屏、键盘、减少动态效果偏好 | 分段控件和布局可操作，无整页水平溢出，焦点清晰 |
| LIB-13 | 伪造其他用户馆 ID、书单 ID 或非法书籍 ID | 服务端拒绝读取/写入，批量反馈不暴露他人书籍资料 |
| LIB-14 | 批量部分失败、设置并发修改 | 结果准确、可重试、无重复关系；设置冲突不静默覆盖 |
| LIB-15 | 原有书库、书架、书单、收藏和客户端回归 | 原行为与历史数据兼容，原列表不混入馆内组织数据 |
| LIB-16 | 数据备份后恢复、新版本读取旧备份 | 新馆数据恢复完整；旧备份可正常使用原书库 |

性能验收建议使用单账户 100 个馆、总书库 10,000 本、单馆 5,000 本的数据集，在明确 NAS 型号、并发数、缓存条件后记录列表/首页接口 P95 和查询次数。禁止全量拉取再分页或按馆藏数线性增加查询；正式实施前补充可复现的数值门槛，未补充时不得声称性能验收完成。
