- 状态：已完成
- 应用版本：`1.44.10`
- 需求内容：继续完善安卓云端结构化书籍阅读，避免打开超长连载时一次下载整本正文，降低首屏等待、流量和内存占用。
- 完成情况：安卓阅读器优先读取后端 Web Publication Manifest，仅请求进度所在章节，并在后台预取相邻章节；目录切换、滚动续章、向前加载和云端书签跳转均可按需获取章节。章节占位目录保持稳定的结构化章节 key，使多端阅读进度能够继续精确恢复；Manifest 不可用、内容不完整或首章请求失败时自动降级到既有整本结构化内容接口，兼容旧服务端。

### REQ-20260921-001 安卓阅读进度后台可靠同步

- 需求时间：2026-09-21
- 完成时间：2026-09-21
- 状态：已完成
- 应用版本：`1.44.8`
- 需求内容：继续完善安卓多端阅读体验，使断网或服务暂不可用时保存的阅读进度能够在网络恢复后自动补传，并向用户展示同步状态。
- 完成情况：进度上传失败后会保存书籍 ID、版本 ID、章节、章节内位置、全书进度、精确 locator 和本地保存时间，并立即触发受网络条件约束的 WorkManager 同步任务；应用启动时和每 15 分钟周期任务会继续补传。同步前比较服务端更新时间，避免旧离线进度覆盖其他设备的新进度。云端设置页新增待同步数量、最近成功时间、错误信息和“立即同步”入口；仅 Wi-Fi 设置同时作用于周期任务和手动任务。退出账号或更换服务器时清理旧账号待同步数据，防止跨账号误传。
- 开源调研：复用 Android 官方 WorkManager、项目现有 DataStore 和 Retrofit，不新增依赖或外部代码；WorkManager 已满足持久化任务、网络约束和指数退避需求。
- 主要改动：扩展 `ServerConfigStore` 待同步进度索引与同步状态；新增 `ReadingProgressSyncWorker` 及周期/即时调度；增强 `ServerRepository` 批量补传、冲突处理和账户隔离；在云端同步设置页展示状态并提供手动同步；应用修订版本升至 1.44.8。
- 验证结果：安卓 `core:network`、`core:data` 与 `app` 单元测试全部通过（Gradle 69 个任务成功）；版本一致性及 `git diff --check` 通过。
