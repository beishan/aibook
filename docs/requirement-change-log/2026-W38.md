- 完成时间：2026-09-14
- 状态：已完成
- 应用版本：`1.33.0`
- 需求内容：爬虫完成书籍采集后，支持不转换为 TXT 或 EPUB 文件，直接加入正式书库并阅读。
- 完成情况：采集书籍现在默认通过“结构化章节”入库，正式书库保存独立、不可变的章节快照，不生成主阅读文件；网页正式阅读器可直接打开结构化版本，并继续使用目录、搜索、阅读进度、阅读时长、书签、高亮、主题和翻页能力。TXT/EPUB 改为可选附加导出，原有文件入库流程保持兼容；采集内容发生变化时可发布新的结构化主版本，并迁移已有阅读进度。
- 主要改动：新增正式书库章节快照实体、仓库和结构化出版物服务；新增接近 Readium Web Publication Manifest 的清单与单章接口；扩展采集入库、版本同步、版本删除及正式阅读内容接口；采集页默认选择结构化入库并将 TXT/EPUB 标记为附加导出；书库、书架、详情和阅读器统一显示“在线章节”；应用次版本升级至 1.33.0。
- 验证结果：新增结构化入库及结构化正文/清单测试，本次相关后端测试 8 项全部通过；排除会在当前环境触发 JVM 原生图像库退出的既有 `CoverControllerTest`、`CoverImageCacheServiceTest` 后，其余后端测试 254 项全部通过；前端 Vite 生产构建通过；`git diff --check` 通过，package/package-lock 版本一致。
