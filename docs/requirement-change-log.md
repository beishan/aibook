# 需求变更记录

本文件为开发需求按周汇总的主记录；每项需求的完整内容保存在对应的周详情文件中。


## 记录规则

- 按需求时间所属 ISO 自然周（周一至周日）归档；需求时间缺失或无法识别时使用需求编号中的日期。
- 同一周复用一个详情文件，周与详情中的最新记录均置于最上方；同一天沿用已有记录顺序。
- 开始开发可登记为进行中；结束前同步更新详情、该周摘要、数量、状态和应用版本。未完成、取消或未验证须如实注明。
- 每项需求使用唯一编号 `REQ-YYYYMMDD-NNN`。历史记录保留原文，既有重复编号不自动合并或改写。
- 仅讨论方案且未修改项目文件无需记录；项目改动须检查使用说明并在详情记录更新或无需调整的原因。

## 主记录格式

```markdown
### YYYY-Www（YYYY-MM-DD 至 YYYY-MM-DD）

- 开发内容：概述本周实际开发主题与主要结果；进行中或部分完成内容注明状态。
- 详情记录：[YYYY-Www.md](requirement-change-log/YYYY-Www.md)（N 条）
```

## 子记录格式

```markdown
### REQ-YYYYMMDD-NNN · 需求标题

- 需求时间：YYYY-MM-DD HH:mm CST
- 完成时间：YYYY-MM-DD HH:mm CST（未完成时如实填写）
- 状态：待处理 / 进行中 / 部分完成 / 已完成 / 已取消
- 应用版本：本需求完成后的版本号
- 需求内容：目标、范围及约束。
- 完成情况：实际结果及未完成项。
- 主要改动：涉及的功能、文件及关键实现。
- 使用说明：更新情况；无需调整时说明核对结果和原因。
- 验证结果：列出执行的验证；未执行时说明原因。
```
