# 需求变更记录

本文件用于持续记录项目开发需求及完成情况，最新记录置于最上方。

## 记录规则

- 每项开发需求使用唯一编号：`REQ-YYYYMMDD-NNN`。
- 开始开发时可先登记为“进行中”；开发完成并验证后更新为“已完成”。
- 每条记录至少包含需求时间、完成时间、需求内容、完成情况、主要改动和验证结果。
- 需求取消、延期或部分完成时，应如实填写状态及未完成原因。
- 仅讨论方案、未产生项目变更的咨询不记入本文件；方案进入开发后再登记。

## 状态说明

| 状态 | 说明 |
|---|---|
| 待处理 | 已确认需求，尚未开始开发 |
| 进行中 | 正在开发或验证 |
| 部分完成 | 已交付部分内容，仍有明确未完成项 |
| 已完成 | 功能开发和必要验证均已完成 |
| 已取消 | 需求已明确取消 |
