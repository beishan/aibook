# 网页手机适配

手机端沿用当前账户的主题与业务设置；响应式布局不新增本地偏好或服务端配置。

- 宽度不超过 768px 时启用手机布局。触控设备宽度不超过 1024px 且高度不超过 500px 时同样启用，兼容手机横屏。
- 三种主题布局共用底部“首页、书库、书架、更多”导航。“更多”提供全部业务入口、个人设置、回收站和退出登录。
- 正式阅读、采集试读及重写编辑隐藏全站导航，使用页面自身的返回入口与工具栏。
- 内容区预留底部导航及系统安全区域；弹窗在视口内滚动，关闭按钮保持可达。
- 书库筛选分为两列，显示模式使用可键盘操作的滑块分段控件；批量操作换行。备份任务与执行记录在手机上纵向展示全部字段。
- 复杂章节与管理表格保留内部横向滚动；避免使用整页隐藏溢出的方式掩盖操作控件。

## 浏览器回归检查

`frontend/scripts/check-mobile-layout.mjs` 使用模拟 API 数据运行，不连接真实账户或更改真实数据。
运行前启动前端开发服务（默认检查地址为 `http://127.0.0.1:3100`）。
检查依赖已有的 Playwright 测试运行时和浏览器，本次未新增项目依赖。

可配置环境变量：

| 变量 | 用途 |
| --- | --- |
| `MOBILE_BASE_URL` | 前端开发服务地址 |
| `MOBILE_PLAYWRIGHT_PATH` | 已安装 Playwright 模块路径；省略时从当前环境解析 |
| `MOBILE_BROWSER_CHANNEL` | 已安装浏览器通道，如 `msedge` 或 `chrome`；省略时使用 Playwright 默认 Chromium |
| `MOBILE_THEMES` | 逗号分隔主题，默认 `macos26,warm,modern` |
| `MOBILE_WIDTHS` | 逗号分隔视口宽度，默认 `320,390,768` |
| `MOBILE_HEIGHT` | 视口高度，默认 `844`；横屏可用宽 `844`、高 `390` |
| `MOBILE_EXTENDED` | 设为 `true` 增加 20 个设置栏目、系列、内容修复、书单及采集中心各 Tab 检查 |
| `MOBILE_SCREENSHOT_DIR` | 可选截图目录 |

配置运行时后，在 `frontend` 执行 `npm run test:mobile-layout`。
默认检查三种布局的 14 个路由、导航抽屉、显示模式键盘切换、上传弹窗及备份详情；另检查登录、注册和桌面导航。
检查结果不能替代 iOS/Android 真机、软键盘、刘海屏安全区及真实 EPUB/PDF 文件验证。
