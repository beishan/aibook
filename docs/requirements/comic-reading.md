# 汗牛充栋 · 漫画阅读需求文档

| 项目 | 内容 |
|---|---|
| 文档状态 | Web 首版已实现，目标 NAS 性能验收待执行 |
| 文档日期 | 2026-11-06 |
| 需求编号 | REQ-20261106-001 |
| 首发范围 | 桌面及移动浏览器，支持服务端书库中的 CBZ |
| 目标用户 | 使用家庭 NAS 私有书库的漫画读者及书库管理者 |

Web 首版采用 CBZ、单页和纵向滚动，默认单页、从左往右、整页适配。目标 NAS 性能指标为待验证目标。具体部署限制和验证范围见文末。

## 1. 背景与目标

汗牛充栋已有 CBZ、CBR 上传和目录扫描入口，书籍卡片也可显示漫画格式标签。当前使用说明区分了「可上传」与「可在线阅读」。本需求补齐从书籍详情打开漫画、阅读、退出以及跨设备续读的流程。

1. 管理者能继续使用现有上传、目录扫描和版本管理流程维护漫画。
2. 读者可以在桌面浏览器阅读分页漫画，也可以在手机浏览器连续下滑阅读条漫。
3. 用户刷新页面、退出或换设备后，可从同一账户、同一文件版本上次阅读的位置继续。
4. 读者可以在整册下载完成前开始阅读。打开大册、快速跳页和多人阅读时，服务端及浏览器资源消耗应有上限。
5. 访问权限沿用书库规则，家庭成员的阅读位置和偏好各自独立。

## 3. 用户与主流程

| 场景 | 用户操作 | 预期结果 |
|---|---|---|
| 导入一册 | 上传 CBZ，或扫描 NAS 漫画目录 | 书库保留原文件，详情显示 CBZ 版本，已有有效封面优先 |
| 打开已有漫画 | 打开早期入库的 CBZ 详情，选择版本后点击阅读 | 直接为该版本建立或获取页清单，无需重新导入 |
| 桌面看分页漫画 | 进入单页模式，设置从右往左，使用方向键或翻页按钮 | 页码按阅读顺序递增，左右键随方向调整 |
| 手机看条漫 | 切到纵向滚动，从当前页继续下滑 | 图片按页清单顺序连续排列，图片到达后页面位置稳定 |
| 跨设备续读 | 设备 A 看至第 37 页并成功同步，设备 B 登录同一账户 | 从同一版本第 37 页打开，纵向模式尽可能恢复页内位置 |
| 阅读其他版本 | 同一本书从 CBZ 版本切到 PDF，稍后切回 | 两个版本各自恢复进度，路由进入对应阅读器 |
| 多人共用书库 | 两个家庭账户打开同一册漫画 | 使用各自的进度和阅读偏好 |

## 4. 功能需求

### 4.1 导入、页清单和封面

- **COM-01 复用导入。** 使用现有上传、扫描、版本替换和下载流程。导入保留原文件。旧版已入库且可访问的 CBZ 应能直接打开。
- **COM-02 识别内容。** 以实际归档内容判断能否读取。首发建议支持 JPEG、PNG、静态 WebP，开发阶段需在目标浏览器和 NAS 环境验证。目录、隐藏文件、系统生成文件、元数据及不支持的附件不进入页清单。加密归档、无有效页面和损坏归档应给出明确提示。
- **COM-03 固定顺序。** 按包内完整相对路径做自然排序。先比较逐层路径，再比较文件名中的数字，确保 `第2话/2.jpg` 早于 `第2话/10.jpg`，且 `第2话` 早于 `第10话`。大小写或前导零造成同序时，以原始路径和归档条目顺序作为稳定的排序依据。重复路径需能区分页面。翻页方向只改变操作映射，页码和排序保持一致。
- **COM-04 封面。** 优先保留已有有效封面。缺少封面时在前 32 页内寻找首张可用的图片，封面生成失败时显示既有默认封面并允许阅读。生成封面应遵循现有隐藏封面规则。
- **COM-05 文件变更。** 文件替换后重新建立清单，旧图片缓存随文件修订失效。旧页码恢复到新文件的有效范围并提示内容已更新。已打开旧文件的会话提示重新载入，旧会话不得覆盖新文件的阅读位置。

### 4.2 入口与工具栏

- **COM-06 阅读入口。** 书库、个人书架、最近阅读等入口沿用现有详情链路。详情根据所选版本决定进入漫画、PDF 或其他阅读器。继续阅读优先恢复可用的上次阅读版本，用户显式选定版本时以该版本为准。原版本不可用时提示重新选择版本。
- **COM-07 工具栏。** 提供返回、书名、页码及总页数、上一页、下一页、跳页、阅读模式、翻页方向和适配方式。窄屏保留返回及页码，将较少使用的设置收进菜单。阅读内容区中央可切换工具栏，键盘焦点进入工具栏时保持可见。
- **COM-08 跳页与边界。** 输入范围为 1 至总页数，确认后跳转。空值、小数和越界输入保留当前页并给出提示。首页禁用上一页，末页禁用下一页。读到末页后允许返回详情或回到首页。错误页提供重试和主动跳过。

### 4.3 单页与滚动模式

| 项目 | 单页翻页 | 纵向滚动 |
|---|---|---|
| 初始展示 | 默认整页适配，支持适宽与放大查看 | 页面按容器适宽等比显示，可纵向连续滑动 |
| 触屏 | 轻触左右区域翻页，中央切换工具栏。放大状态下优先拖动画面 | 垂直滑动，中央可切换工具栏。工具栏保留上一页、下一页和跳页 |
| 键盘 | 左右方向键按阅读方向映射。上一页、下一页按钮有明确语义 | 沿用滚动习惯，聚焦导航按钮时可用键盘操作 |
| 页码 | 当前展示页 | 以可视区域固定参考线所在页为当前页，加载占位使用稳定高度 |
| 方向 | 从左往右时右侧为下一页，从右往左时左侧为下一页 | 从上往下滚动 |

- **COM-09 保持阅读锚点。** 改变模式、窗口尺寸或屏幕方向后保留当前逻辑页。纵向模式优先恢复该页相对位置。切到单页再切回纵向且未翻页时，可继续使用原页内位置。
- **COM-10 图片放大。** 支持从适配状态放大查看细节及恢复适配。图片宽高比保持不变，放大后可平移。翻页后回到该模式的适配状态，输入框和菜单打开时不触发全局翻页快捷键。
- **COM-11 可访问性。** 控件有可辨识名称、可见焦点和明确禁用状态，触屏控件可触达。模式和方向选择遵循项目滑块分段控件规范，支持键盘切换、窄屏横向滚动及减少动画偏好。

### 4.4 阅读进度、读完状态和偏好

- **COM-12 位置模型。** 按账户、书籍 ID、文件版本 ID 保存最近页码。纵向模式可附带该页内的相对偏移，并与文件修订关联。对外页码从 1 开始。首次打开显示第 1 页，成功展示后才建立阅读记录。
- **COM-13 进度写入。** 翻页或滚动稳定后合并写入。切页、主动返回、浏览器隐藏时尽力保存最新已展示位置。连续跳页只提交最终已展示的位置。页面加载失败时保留上一次有效位置。
- **COM-14 并发与重试。** 网络中断时保留当前会话内待同步位置并提示，网络恢复后重试。以服务端进度修订做条件更新，过期写入不得覆盖其他设备的新进度。同一会话中，较早请求的回包不得覆盖较新操作。用户主动往回翻后依然允许保存较小页码。遇到跨设备冲突时保留本次画面，提示已有更新，并允许载入已同步位置或明确以当前位置继续。
- **COM-15 聚合与完成。** 接入现有阅读历史和继续阅读，展示「第 N / M 页」。到达末页且图片成功展示后记录读完，未读完时继续阅读展示实际进度。单页漫画在成功展示后可读完。完成状态和最近位置分开表达，读完后回看前页可保存位置。
- **COM-16 账户偏好。** 服务端保存漫画阅读模式、单页方向及适配方式。首次使用建议默认单页、从左往右、整页适配，用户更改后换浏览器也可恢复。纵向模式保留单页方向设置，切回单页时生效。不同账户的设置互相隔离。

## 5. 数据与服务边界

以下是客户端与服务端的行为约定，具体路径、字段命名和是否需要迁移由实现方案确定。

| 能力 | 输入 | 输出与约束 |
|---|---|---|
| 查询可读性和页清单 | 书籍 ID、版本 ID | 返回可读状态、原因、页数、稳定页索引、文件修订。能低成本获取时返回宽高，供预留空间 |
| 获取单页 | 书籍 ID、版本 ID、文件修订、页码 | 返回经鉴权的原图字节及可信内容类型。页码错误、文件已替换和内容损坏可以区分 |
| 读取和写入进度 | 当前账户、书籍 ID、版本 ID、位置和进度修订 | 优先复用既有版本进度与定位字段，明确空记录、冲突及已删除版本的处理 |
| 读取和保存偏好 | 当前账户及漫画偏好 | 优先复用服务端账户偏好机制，跨设备恢复 |
| 封面 | 可访问的版本和稳定页清单 | 复用既有封面存储与鉴权，按文件修订失效 |

服务端校验书籍和版本的归属关系，对页清单和每次取图使用同一套书库授权规则。浏览器收到的是应用资源标识，归档条目路径和 NAS 路径留在服务端。图像缓存按文件修订区分，并沿用私有资源缓存策略。应用不得把漫画文件或图片发往外部服务。

## 6. 性能、资源与容错

- 首屏先取清单和当前页，再有限预取邻近页。跳页、切换版本和退出时取消过期请求，旧响应不得覆盖当前画面。
- 纵向模式按窗口加载图片，预留尺寸减少滚动跳动，离开较远的页面释放解码后的图片资源。重试单页时保留其余页面状态。
- 服务端对归档大小、归档条目数、单页解压字节、像素尺寸及并发解码设上限。归档条目按受限流读取，避免写出任意文件。超过上限时返回可识别的错误。
- 优先使用现有技术栈。进入开发后按项目规范调研成熟开源方案，评估归档兼容性、许可证、维护与安全情况、NAS 资源和集成成本。需要引入依赖、外部代码或服务时提交候选方案供确认。

| 建议验收环境 | 样本与指标 |
|---|---|
| 家庭 NAS，Docker Compose，客户端通过局域网连接 | 记录 NAS 型号、CPU、内存、浏览器、网络及镜像版本 |
| 常规样本 | 约 200 页、200 MB，含嵌套目录。冷打开至首张可见图建议 P95 ≤ 3 秒，热缓存相邻翻页建议 P95 ≤ 500 毫秒 |
| 压力样本 | 约 500 页、1 GB，含高像素页和长条图。验证可在整册下载前开始阅读，连续浏览 100 页无崩溃，跳页后仅加载目标附近页面 |
| 并发样本 | 两个账户分别浏览不同漫画并连续跳页，观察取图响应、错误率及内存峰值 |
| 测量方式 | 冷打开清理相关客户端和服务端缓存，热翻页允许命中预取。首屏与翻页分别记录至少 20 次并保留样本数据 |

上表时延为评审目标。实现时应在实际部署环境测得基线，再确定发布门槛和归档限额。

## 7. 异常提示

| 情况 | 用户看到的反馈 | 可执行操作 |
|---|---|---|
| CBR 或其他未开放格式 | 该版本暂不支持在线阅读 | 下载原文件或选择可读版本 |
| 文件被移动、删除或 NAS 暂不可读 | 漫画文件暂不可用 | 重试或返回详情 |
| 空包、加密或损坏归档 | 显示具体原因 | 返回详情，更换文件版本 |
| 其中一页图片损坏 | 保留页码并显示单页加载失败 | 重试、跳过、返回详情 |
| 网络断开 | 当前图片保留，待取页面及进度显示未同步状态 | 恢复网络后重试 |
| 失去权限或登录过期 | 使用项目现有登录及无权限提示 | 重新登录或返回 |
| 阅读中的文件已被替换 | 提示漫画文件已更新 | 重新加载并恢复到有效页码 |
| 超出归档或图片限额 | 说明触发的限制类别 | 返回详情，换用符合限制的文件 |

## 9. 交付顺序与后续决策

1. 验证样本 CBZ 的排序、图片兼容性、文件替换、鉴权和大册读取，确定首发限额。
2. 接通书籍详情、版本选择、页清单、按需取图及两种 Web 阅读模式。
3. 接入账户偏好、进度同步、继续阅读和读完状态，补齐错误处理。
4. 使用桌面、移动浏览器及目标 NAS 验收，补充使用说明后发布。

| 决策项 | 首版选择或建议 | 会影响的范围 |

## 10. Web 首版实现说明

- 使用 Java 21 的 ZIP 接口、现有 Caffeine 和账户偏好。逐页请求鉴权，最多同时读取四页或归档。客户端每个阅读页同时请求至多两张图片，纵向模式只渲染可视区及邻近页面。
- 归档上限为 2 GiB、10000 个条目及 8 MiB 的中央目录。单页上限为 16 MiB、4000 万像素且任一边不超过 32768 像素。加密、分卷及使用 ZIP64 中央目录的包会给出限制提示。网页上传沿用现有上传限制，超限的上传文件可改走 NAS 扫描。
- JPEG、PNG 使用 Java 自带解码器读取尺寸和检查封面，静态 WebP 由服务端检查容器头及尺寸，最终由浏览器解码。漫画坏页保留在页清单中，读者可重试或跳过。
- 性能指标需在目标 NAS 上测量。现阶段的浏览器验证使用模拟书库接口，不能作为真实 NAS、移动真机或并发时延验收结果。
