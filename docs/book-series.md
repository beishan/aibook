# 系列与阅读顺序

## 使用

1. 在书库编辑书籍，或在书籍详情的“系列与阅读顺序”区域点击“设置系列”。
2. 填写系列名称和卷序。可选择已存在的系列，也可输入新名称；同一用户内相同名称的书籍自动归组。
3. 从书库顶部“系列与阅读顺序”进入系列页，查看卷册顺序、阅读统计和可能缺卷的提示。系列页可直接编辑单本书籍。
4. 书籍详情会提供下一卷的阅读入口。当前卷已读完时显示“读完这本，接着读”。

卷序支持 0–9999.99，最多两位小数；0 可用于前传，1.5 等小数可用于番外。卷序未填写的书排在末尾；相同卷序按书籍 ID 稳定排序。
清空系列名称会同时清空卷序，将该书移出系列。仅修改书名等其他元数据不会清除系列信息。

## 提示的含义

- 缺卷提示只检查 1 到已登记最大整数卷号之间的空缺，连续空缺合并显示；不会猜测全系列总卷数、出版状态或小数番外是否缺失。
- 相同卷序存在多条记录时显示检查提示，不自动合并或删除书籍。
- 下一卷选择大于当前卷序的最小卷序，不把同卷的另一条记录当作下一卷。未填写当前卷序时不推荐，最后一卷也不会跳到其他系列。
- 系列名称区分大小写，首尾空白移除，连续普通空白归一为一个空格。不同系列同名时可在名称中补充作者或版本以区分。

## 数据与兼容

- `books` 新增可空字段 `series_name`（120 字符）、`series_index`（numeric(6,2)），新增用户与系列名称组合索引；沿用项目现有 Hibernate schema update 更新机制。
- `GET /api/series` 返回当前用户可见书库的系列名称、入库数量和已读数量。
- `GET /api/series/books?name=...` 返回该系列的轻量卷册信息，按数字卷序排序。两接口均要求登录，排除回收站与隐藏扫描目录中的书籍。
- `PUT /api/books/{id}/metadata` 支持 `seriesName` 和 `seriesIndex`；提交名称时一并替换卷序，空名称表示移出系列。
- 格式转换任务从书库创建时携带系列信息，转换结果新建书籍时保存系列信息。多版本合并补齐缺失的系列信息，不覆盖主记录已有的不同系列。
- 既有藏书的系列信息需手动填写；此版本没有批量推断书名卷号、读取 EPUB 内嵌系列标签或回填历史转换结果。

## 实现与验证

参考 [Calibre 的系列名称与卷序元数据设计](https://manual.calibre-ebook.com/gui.html?highlight=create+catalog)，在项目现有 Vue、Spring 与 PostgreSQL 中实现，无新增依赖和服务。
后端测试覆盖数字排序、用户隔离、字段校验、元数据保留与清除、多版本信息保留，以及使用真实 Hibernate 实体映射解析系列查询。
浏览器采用隔离的模拟数据检查系列展示、缺卷提示、编辑后重排及 390 像素宽度布局。尚未进行 NAS 上的数据库升级与真实书库联调。
