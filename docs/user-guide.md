# 使用说明维护

完整说明的唯一内容来源为 [user-guide.md](../frontend/src/content/user-guide.md)，随前端打包，入口是「系统设置 → 系统管理 → 使用说明」，所有登录用户可查看。

内容放在前端构建上下文内，保证现有 Docker 构建无需访问仓库外文件。页面不依赖网络或第三方文档服务；每次项目改动必须检查对应章节；涉及功能、操作入口、流程、配置、权限、限制或结果变化时，须在同一需求中同步更新正文。无用户可见影响时，在需求变更记录中注明“使用说明已核对，无需调整”及原因。详细要求见项目 `AGENTS.md` 的“使用说明同步”。

维护格式：一级标题为文档名称，二级标题为目录章节，三级标题为操作主题；正文使用普通段落、无序列表或编号列表。当前阅读器按这些固定格式渲染纯文本，不执行 HTML，不解析任意 Markdown 扩展。新增章节应保留实际入口、操作步骤、结果、权限和适用范围；不要把计划中的能力记为已实现。

页面提供章节目录、正文搜索、无匹配提示、离线 Markdown 下载。搜索为所有词均命中的章节匹配，支持空格分词及大小写/全半角归一化，不更改账户偏好。
