## 统一视觉与交互方向

- 保留参考图的浅蓝灰背景、冷白阅读区域、蓝色选中态、细描边和轻量圆角。
- 常规状态保留顶部全局导航；左侧上方展示书籍封面、书名、作者和书架状态。
- 目录、书签、笔记、划线采用滑块分段控件，后续实现需支持键盘切换、焦点、窄屏横向滚动及减少动态效果偏好。
- 正文使用中文衬线字体，界面控件使用无衬线字体；侧栏和设置面板展开后应调整正文宽度，避免遮住内容。
- 全局搜索与书内搜索保持明确区别；选中文字后的工具条靠近选区。
- 阅读偏好在正式实现时按当前账户由服务端保存。

## 资料范围

原始参考图直接复制自用户附件，其余状态通过内置 ImageGen 以该附件为参考生成；生成提示词见 [prompts.md](prompts.md)。图中书籍内容、数量、日期、页面位置和部分控件为概念示意，不代表当前应用已经实现这些界面或能力。不同图片中的图标、间距和文字细节在正式实现时需按统一组件收敛。

本次仅保存设计资料，没有修改阅读器页面或用户操作流程。
